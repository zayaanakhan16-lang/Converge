# Repository notes

Converge: Android-first Expo/React Native app plus a FastAPI backend. Four
languages, each with one job — TypeScript builds the product, Python runs the
intelligence services, Java parses the WAV container, C++ computes the waveform
envelope. Do not add files in a language to lengthen the list.

## Commands

```bash
# Mobile
cd mobile && npx tsc --noEmit && npx eslint . --max-warnings 0 && npx jest
npx expo export --platform android --output-dir /tmp/export   # bundle check

# Backend (a .venv already exists)
cd backend && ./.venv/bin/python -m pytest

# Native host suites
cd android-native/java && ./run_tests.sh    # needs a JDK; javac must be on PATH
cd android-native/cpp  && ./run_tests.sh

# SQL suites — need a freshly migrated, unseeded database
DATABASE_URL=postgres://... ./scripts/run_sql_tests.sh
```

The SQL wrapper connects with peer auth as the wrong role, so override it with
`PSQL="psql -U <user>"`. Running the suites against a seeded database produces
false failures: the seed inserts rows the RLS tests expect to be absent.

## Layout

- `mobile/src/services/` — a `Repository` interface with Supabase and demo
  implementations. Demo mode is the default and is labelled in the UI.
- `supabase/migrations/` — 12 migrations. Privacy rules live here, not in the
  app: a restriction enforced only in the client is not a restriction.
- `backend/app/services/` — matching, translation, coach, moderation, geocoding.
  Every optional capability reports itself unavailable rather than inventing
  output. `/health` lists what is configured.
- `brand/` — tokens are generated by `brand/tools/generate_brand.py`; the JSON it
  writes is the single source of truth for both the app and the exports.

## Conventions

- Never claim a feature works when it is only a placeholder. Translation, voice
  transcription, waveforms and the model coach all degrade visibly and say why.
- No unexplained compatibility percentages. Matching returns reasons as text.
- No hardcoded secrets. Only the Supabase URL and anon key reach the client.
- The health router is mounted at `/health`; the rest are under `/api/v1`.

## Gotchas

- Hard-navigating a URL resets the demo session by design — it is in-memory.
  Sign in, then navigate through in-app links.
- Demo credentials: `amara@converge.demo` / `converge-demo`.
- `android/` is generated by Expo and git-ignored. Native config belongs in
  `app.json` and `plugins/withConvergeAudio.js`, never in generated files.
